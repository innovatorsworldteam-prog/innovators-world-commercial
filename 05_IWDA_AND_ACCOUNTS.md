# IWDA + Accounts

Flow:
Landing → Start IWDA → Assessment → Result → Personal Insight → Create Account/Sign In → My Innovators World → Recommended Next Experience

Account functions:
- sign up
- sign in
- sign out
- recovery
- profile
- consent/privacy controls

My Innovators World:
- IWDA result
- saved challenges
- completed challenges
- achievements
- programme participation
- journey history
Future: Innovation Passport, projects, badges, showcases, moderated community.
