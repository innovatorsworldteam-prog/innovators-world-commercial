# Product Constitution
Innovators World is an innovation ecosystem where curiosity becomes questions, questions become ideas, ideas become experiments, and experiments become meaningful action.

Core journey:
SEE → QUESTION → EXPLORE → CREATE → RETURN → BELONG → PARTICIPATE → BUY / ENQUIRE / PARTNER

Methodology:
OBSERVE → QUESTION → IMAGINE → CREATE → TEST → IMPROVE

IWDA is FREE and is the principal acquisition/engagement mechanism.
